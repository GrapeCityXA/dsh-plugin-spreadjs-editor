SpreadJS Designer commercial components. Those components remain subject to

The prebuilt client contains the SpreadJS and SpreadJS Designer components
declared in package.json — the versions recorded there are authoritative, and
this file deliberately does not repeat them. Original license and notice files
supplied by those packages are preserved under lib/licenses. Copyright notices
embedded in the client bundle are retained. React and DSH are supplied by the
