# 桌面授权策略

桌面环境使用本编辑器，必须取得适用于该场景的**无限制授权**，并同时覆盖 **SpreadJS** 和 **Designer Component**。

没有上述授权，桌面版无法使用本编辑器。SpreadJS 和 Designer Component 的授权需分别配置，缺少任一组件的适用授权均无法使用完整编辑器。

免费插件不包含 SpreadJS 或 Designer Component 授权。无 key 的本地开发仅限供应商试用条款允许的 HTTP(S) 回环环境；桌面环境不能依赖这类本地试用。

## English

Use of this editor in a desktop environment requires **unrestricted licenses** applicable to that use, covering both **SpreadJS** and **Designer Component**.

Without these licenses, the editor cannot be used in the desktop app. SpreadJS and Designer Component license keys must be configured separately; the complete editor requires applicable licenses for both components.

The free plugin does not include SpreadJS or Designer Component licenses. Keyless local development is limited to HTTP(S) loopback environments permitted by the vendor's trial terms; desktop environments cannot rely on that local trial mode.
